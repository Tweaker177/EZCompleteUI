Golden Mandarin (金帽福运) for EZCompleteUI

Fastest: from your repo root run   git apply golden-mandarin.patch
That adds every new file and edits BRSlotGamePickerViewController.m, Makefile and
Resources/en.lproj/Localizable.strings. The loose BRGoldenMandarin* files and
GoldenMandarinServer/ here are the same content, if you'd rather copy by hand.

Server: see GoldenMandarinServer/README.md (run the SQL, then deploy the edge function).
